# Student Companion App 📚

A simple React Native app built with Expo to help students manage their daily tasks.

## Features

- Add and view tasks
- Mark tasks as completed (with checkbox)
- Auto strike-through for completed tasks
- Light/Dark theme support based on system settings

## Getting Started

### Prerequisites

- Node.js (v16 recommended)
- Expo CLI (`npm install -g expo-cli`)
- Git
- Android Emulator or Expo Go app on your phone

### Installation

```bash
git clone https://github.com/misahl/Student-Companion-App.git
cd Student-Companion-App
npm install
